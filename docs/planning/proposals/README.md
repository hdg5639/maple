## 1. 개요 및 발의 배경 (Executive Summary)

현재 OpenMaple의 장비 시스템은 기초적인 7회 업그레이드 슬롯(`upgradeSlots: 7`)과 단순 3종 주문서(100%, 60%, 10%) 위주의 최소 기능(MVP)으로 구현되어 있습니다. 

그러나 정통 메이플스토리의 핵심 재미인 **"심장 쫄깃한 주문서 작(Scrolling)", "부위별 특화 주문서 파밍", "주문서 완작 후 한계를 돌파하는 스타포스(Star Force)", "혼돈의 주문서 대박/쪽박의 카타르시스"**를 제공하기에는 시각적 연출과 게임 기획적 깊이가 크게 부족합니다.

또한 로그인/회원가입 시스템이 백엔드 DB와 로비 모달 형태로 이미 구축되어 있음에도 불구하고, 최초 접속 시 타이틀 화면 없이 게스트 모드로 인게임 직행하던 사용자 경험과 마찬가지로, **강화 시스템 역시 인벤토리 하단 구석의 작은 드롭다운에 머물러 있어 유저에게 도파민과 시각적 타격감을 전혀 전달하지 못하고 있습니다.**

본 안건서는 OpenMaple의 아이템 강화 메커니즘을 2000년대 클래식 메이플의 감성과 상용 수준의 타격감(Juice), 그리고 서버 무결성(Server-Authoritative)을 결합하여 완벽한 RPG 엔드게임 파밍 엔진으로 전면 개편하기 위한 종합 개선방안을 제시합니다.

## 3. 핵심 개선 목표 (To-Be Vision)

1. **클래식 원작 100% 고증 주문서 생태계 구축**: 무기별/방어구별/악세서리별 주문서 분리 및 저주의 주문서(Cursed Scroll 30%/70%) 도입.
2. **도파민 극대화 특수 주문서 시스템**: 혼돈의 주문서 60%(랜덤 스탯 -5 ~ +5 증감), 순백의 주문서(실패 슬롯 복구), 백의 주문서(파괴 방지).
3. **스타포스(Star Force) 5성 한계 돌파**: 주문서 업그레이드 슬롯을 0까지 소모한 완작 장비에 메소와 강화 확률을 이용해 별(★)을 부여하는 메이플식 2차 강화 도입.
4. **'메이플 대장간(인챈트 제단)' 전용 UI & 2단계 서스펜스 연출**:
   - 중앙 장비 슬롯 + 주문서 드래그 앤 드롭 안착.
   - 강화 시도 시 **1.8초간 심장 박동(Heartbeat) 음향과 함께 마법진 게이지 차오름 연출**.
   - 성공 시 황금빛 폭죽과 팡파레 + 장비 테두리 발광, 실패 시 잿더미 연기 효과.
5. **서버 권한 무결점 원자적 트랜잭션**: 클라이언트 변조 및 강제종료(F5)를 이용한 롤백 어뷰징을 원천 봉쇄하는 SQLite WAL 2단계 커밋.

## 4. 신규 추가 및 개편 기능 상세 명세 (Detailed Feature Specifications)

### 4.1. 정통 메이플 주문서 라인업 대폭 확충

#### A. 부위별 일반 주문서 (100% / 60% / 10%)
- **무기 공격력/마력 주문서**:
  - 한손검, 두손검, 단검, 활, 석궁, 아대(공격력 +1, +2, +5)
  - 완드, 스태프(마력 +1, +2, +5)
- **방어구 및 악세서리 주문서**:
  - **장갑 공격력 주문서(장공)**: 100%(공+1), 60%(공+2), 10%(공+3) -> *메이플 최고 인기 주문서*
  - **투구 체력/지력 주문서**: 100%(HP+10), 60%(HP+30), 10%(HP+50, INT+1)
  - **전신갑옷 민첩/방어 주문서**: 100%(DEX+1, 물방+1), 60%(DEX+2, 물방+2), 10%(DEX+5, 물방+5)
  - **신발 이동속도/점프력 주문서**: 100%(이속+1), 60%(이속+2, 점프+1), 10%(이속+3, 점프+2, DEX+1)
  - **망토 힘/덱/인/럭 주문서**: 스탯 특화 인챈트

#### B. 저주의 주문서 (Cursed Dark Scrolls: 70% / 30%)
- **70% 저주의 주문서**: 성공 확률 70% (스탯은 기존 60% 주문서보다 우수), 실패 시 **50% 확률로 장비 즉시 파괴(소멸)**.
- **30% 저주의 주문서**: 성공 확률 30% (스탯은 기존 10% 주문서급 + 추가 스탯), 실패 시 **50% 확률로 장비 즉시 파괴(소멸)**.
- **파괴 보호 룰**: 파괴 시 인벤토리 장비 탭에서 영구 삭제되며, 묘비 파티클 및 전용 사운드 출력.

#### C. 엔드게임 특수 주문서 4종
1. **혼돈의 주문서 60% (Chaos Scroll)**:
   - 장비가 가진 모든 기존 스탯(공격력, 마력, 방어력, STR, DEX, INT, LUK, 이동속도, 점프력)에 대해 각각 `-5 ~ +5` 범위의 난수를 독립적으로 가감.
   - 슬롯 1회 소모, 성공률 60%, 실패 시 옵션 불변 및 슬롯만 1회 차감.
2. **순백의 주문서 1% / 5% / 10% (Clean Slate Scroll)**:
   - 주문서 작 실패로 날아간 업그레이드 가능 횟수를 1회 복구 (`upgradeSlots + 1`).
   - 단, 기본 장비의 최대 슬롯 수(예: 7회)를 초과할 수 없음.
   - 실패 시 장비 파괴 위험(저주형 순백의 경우) 옵션 선택 가능.
3. **이노센트 주문서 (Innocence Scroll 50%)**:
   - 주문서 작이 망한 장비를 최초 획득 당시의 순정(Clean) 상태로 스탯 및 잔여 슬롯 100% 원상 복구.
4. **백의 주문서 (White Scroll)**:
   - 강화 시도 시 함께 등록하면, 주문서가 실패하더라도 **업그레이드 슬롯 차감을 1회 무효화**하여 보존.

### 4.2. 스타포스(Star Force) 5성 강화 시스템

주문서 업그레이드 슬롯(`upgradeSlots`)이 0이 된 완작 장비에만 해금되는 심화 스펙업 시스템입니다.

```mermaid
flowchart LR
    A["미강화 순정 장비"] --> B["주문서 작 진행\n(잔여 슬롯 소모)"]
    B --> C{"잔여 슬롯 = 0\n(완작 달성?)"}
    C -- 아니오 --> B
    C -- 예 (완작) --> D["★ 스타포스 제단 해금"]
    D --> E["1성 강화 시도\n(성공 95% / 실패 5%)"]
    E --> F["2성 강화 시도\n(성공 90% / 실패 10%)"]
    F --> G["3성 강화 시도\n(성공 85% / 실패 15%)"]
    G --> H["4성 강화 시도\n(성공 80% / 실패 20%)"]
    H --> I["5성 궁극 강화\n(성공 70% / 실패 25% / 하락 5%)"]
```

- **강화 비용**: 대상 장비의 요구 레벨(`reqLevel`)과 현재 성급(`starCount`)에 비례하는 메소(Meso) 소모.
- **강화 효과**:
  - 무기: 1성당 공격력/마력 +2~4 및 주스탯 +2
  - 방어구: 1성당 방어력 +5, MaxHP +20, 올스탯 +1
- **UI 표시**: 아이템 툴팁 상단에 황금빛 별 아이콘(★ ★ ★ ☆ ☆) 실시간 렌더링.

### 4.3. '대장간(인챈트 제단)' 전용 UI & 시각적 타격감(Juice)

인벤토리 내부의 답답한 텍스트 폼을 철폐하고, 화면 중앙에 클래식 오크목과 황금 리벳으로 테두리된 **[빅토리아 아일랜드 전용 강화 제단 모달]**을 신설합니다:

```
+-------------------------------------------------------------------+
|  🍁 빅토리아 대장간 - 주문서 인챈트 & 스타포스 제단          [X]  |
+-------------------------------------------------------------------+
|                                                                   |
|     [ 장비 슬롯 ]                     [ 주문서/스타 슬롯 ]         |
|   +---------------+                 +-----------------+           |
|   |   🗡️ 하이랜더 |  +------------> | 📜 무기공격 60% |           |
|   |     (+3 / 4)  |                 |  (성공률: 60%)  |           |
|   +---------------+                 +-----------------+           |
|                                                                   |
|   -------------------------------------------------------------   |
|   [예상 인챈트 결과 프리뷰]                                        |
|   - 공격력: 56 -> 58 (+2 증가)                                    |
|   - 성공 확률: 60%  |  실패 확률: 40%  |  파괴 확률: 0%            |
|   - 소모 비용: 15,000 메소                                        |
|                                                                   |
|   [================= 1.8초 서스펜스 게이지 ==================]    |
|                                                                   |
|              [  🔥 주문서 바르기 (강화 시작)  ]                     |
+-------------------------------------------------------------------+
```

#### 연출 애니메이션 단계 (The 3-Act Theater)
1. **1막 - 기 모으기 (Charge & Suspense, 1.2초)**:
   - 강화 버튼 클릭 시 화면 배경 암전(Vignette).
   - 제단 중심부에서 청백색 마법진이 회전하며 `Audio.playHeartbeatTension()` 심장 박동 사운드 재생.
2. **2막 - 결전의 섬광 (Flash & Climax, 0.4초)**:
   - 주문서 양피지가 불타오르며 장비 아이콘 속으로 흡수.
3. **3막 - 결과 표출 (Resolution & Euphoria)**:
   - **성공 시**: 상단 'SUCCESS' 폰트 출력, 화면 가득 금빛 별가루 파티클 확산, 레벨업 팡파레와 맞먹는 찬란한 챠르릉 차임벨 사운드, 장비 외곽선 1.5초간 골드 글로우.
   - **실패 시**: 'FAILED' 둔탁한 폰트, 검은 재와 연기 파티클, 쓸쓸한 "푸슉" 증기음.
   - **파괴 시**: 경고 사이렌, 장비가 산산조각 나는 유리 파편 파티클, 화면 진동(Shake Magnitude 8, 0.5초).

### 4.4. 몬스터/보스별 주문서 드롭 테이블 생태계 연계

상점에서 기본 주문서(100%)만 팔고, 고급 주문서(60%, 10%, 저주, 혼돈)는 필드 사냥과 보스 공략을 통해서만 획득 가능하도록 파밍 경제를 순환시킵니다:

| 몬스터 / 보스 | 주요 드롭 주문서 및 확률 | 파밍 의도 |
| :--- | :--- | :--- |
| **슬라임 / 초록달팽이** | 투구 방어력 주문서 100%, 귀환 주문서 | 초반 튜토리얼 성격 주문서 |
| **와일드보어 / 돼지** | 한손검 공격력 주문서 60%, 방패 방어력 60% | 15~30레벨 전사 파밍 명소 |
| **주니어레이스 / 커즈아이** | 장갑 민첩성 주문서 60%, 신발 이동속도 60% | 기동성/명중률 세팅용 |
| **쿨리좀비 / 드레이크** | **장갑 공격력 주문서 60% (3%)**, 두손검 공격력 60% | 중레벨 핵심 노가다 던전 |
| **킹슬라임 (필드보스)** | **장갑 공격력 주문서 10% (15%)**, 전신갑옷 민첩 60% | 저레벨 파티 보스 보상 |
| **주니어발록 (심층보스)** | **혼돈의 주문서 60% (10%)**, 30% 저주의 주문서 | 하이엔드 도박형 주문서 파밍 |
| **자쿰 (대형 레이드)** | **순백의 주문서 10% (25%)**, 자쿰의 투구 전용 작 주문서 | 최종 종결 스펙업 보상 |

## 5. 아키텍처 및 무결성 설계 (Data Model & Server-Authoritative)

```json
{
  "item_uuid": "eq_highlander_a891f4c2",
  "id": "wp_highlander",
  "name": "하이랜더",
  "category": "두손검",
  "reqLevel": 30,
  "baseAtk": 50,
  "rolledAtk": 52,
  "bonusAtk": 8,
  "enhancements": 4,
  "failedCount": 1,
  "upgradeSlots": 2,
  "maxUpgradeSlots": 7,
  "starCount": 0,
  "history": [
    { "type": "scroll_atk_60", "success": true, "statGain": { "atk": 2 }, "timestamp": 1729831200 },
    { "type": "scroll_atk_10", "success": false, "statGain": {}, "timestamp": 1729831250 }
  ]
}
```

### 5.2. 서버 트랜잭션 흐름도 (Zero-Rollback & Anti-Cheat)

```mermaid
sequenceDiagram
    autonumber
    actor Player as 클라이언트 (브라우저)
    participant Net as NetworkManager
    participant Server as server.py (WebSocket)
    participant DB as SQLite (openmaple.db WAL)

    Player->>Net: requestServerEnchant(itemUuid, scrollId)
    Net->>Server: {"type": "server_enchant", "charId": 1, "itemUuid": "...", "scrollId": "..."}
    Note over Server: 1. 인벤토리 내 대상 장비 & 주문서 실존 검증<br/>2. 잔여 슬롯/메소 조건 검증<br/>3. 서버 사이드 난수 시드(CSPRNG) 주사위 판정
    Server->>DB: BEGIN IMMEDIATE TRANSACTION;
    alt 강화 성공
        Server->>DB: 주문서 차감 + 장비 스탯 가산 + 슬롯 차감
    else 강화 실패 (일반)
        Server->>DB: 주문서 차감 + 슬롯 차감
    else 파괴 (저주의 주문서)
        Server->>DB: 장비 행 삭제(DELETE) + 주문서 차감
    end
    Server->>DB: COMMIT; (WAL 동기화)
    Server-->>Net: {"type": "server_enchant_result", "success": true, "result": "...", "item": {...}}
    Net-->>Player: 연출 재생 (오디오 Chime + 폭죽 파티클) 및 인벤토리 HUD 갱신
```

## 7. 기대 효과

1. **원작 감성의 완벽한 부활**: 단순 숫자 놀음이 아닌, 실패 시의 탄식과 성공 시의 환희가 교차하는 클래식 메이플 고유의 "도파민 루프" 복원.
2. **사냥과 보스 레이드의 목적성 부여**: 장공 60%, 혼돈의 주문서 등 고가치 주문서 파밍을 통해 사냥터 방문 및 보스 레이드(자쿰, 킹슬라임) 참여 동기 극대화.
3. **경제 밸런스 안정화**: 스타포스 및 주문서 강화를 통한 대량의 메소 싱크(Sink) 창출로 인게임 경제 인플레이션 방지.
4. **Agent-Native 무결점 유지**: 모든 강화 동작이 서버 사이드 SQLite WAL 트랜잭션과 CDP 자동화 테스트 스위트(`run_qa.py`)로 보호되어 데이터 유실 0% 보장.
