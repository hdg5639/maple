# 🍁 클래식 메이플스토리 (Pre-Big Bang) 전 직업 스킬 대도감 및 클라이언트 엔진 구현 명세서

## 1. 개요 및 설계 철학 (Architectural Vision)

본 문서는 **2000년대 빅뱅 이전 넥슨 정통 클래식 메이플스토리(GMS v62 / KMS Classic)**에 등장하는 전 직업군(초보자, 전사, 마법사, 궁수, 도적, 해적)의 1차부터 4차까지의 핵심 스킬을 전수 조사하고, 이를 웹 바닐라 기반 2D 게임 엔진(`OpenMaple`)에서 **단 1px의 오차나 타협 없이 극상의 타격감(Juice), 정통 물리 일루전, 투사체 탄도학, 분신 미러링 연계**로 구현하기 위한 절대적 구현 청사진(Technical Implementation Blueprint)입니다.

---

## 2. 엔진 레벨 공통 스킬 아키텍처 (Engine Primitives)

모든 스킬은 다음 5대 기술적 원칙에 따라 표준화된 엔진 모듈과 상호작용합니다:

```
┌─────────────────────────────────────────────────────────────────────────┐
│                           Skill Execution Flow                          │
├─────────────────┬───────────────────┬───────────────────┬───────────────┤
│ 1. Cast / Input │ 2. Aim & Trajectory│ 3. Swept Collision│ 4. Impact Juice│
│  - Cost check   │  - Auto-Aim ray   │  - Penetration    │  - Hitstop    │
│  - Attack timer │  - Velocity vector│  - Terrain check  │  - Digits     │
│  - Action frame │  - Spread angle   │  - Multi-target   │  - Shake/Flash│
└─────────────────┴───────────────────┴───────────────────┴───────────────┘
```

1. **관통형 투사체 탄도학 (Swept Multi-Target Piercing)**:
   - `pierce: true`, `maxTargets: N`, `hitTargets: Set` 구조를 통해, 투사체가 첫 타겟에 소멸하지 않고 전방의 적들을 거리순으로 일렬 관통(`Candidate Sort by Hit Time`).
2. **시차 다단히트 누적기 (Staggered Multi-Hit Delay Loop)**:
   - 모든 다단히트 스킬(새비지블로우 6타, 스트레이프 4타, 드래곤버스터 3타)은 단일 프레임 연타를 금지하고, $35 \sim 65\text{ms}$의 시차 딜레이(`SkillRegistry.schedule`)를 두고 튀어오르는 대미지 폰트 팝업.
3. **섀도우 파트너 복제 엔진 (Shadow Partner Ghost Lag & Mirror Strike)**:
   - 도적 본체 공격 시 $80\text{ms}$ 시차를 두고 분신 위치에서 50% 위력의 동일 공격(투사체 2배 발사 / 근접 2배 연타)을 100% 미러링.
4. **흡혈 및 특수 상태이상 (Drain, Snare, Freeze, Stun)**:
   - 투사체 및 근접 공격에 `drainRate`(피해량 비례 HP 흡수), `snareDuration`(이동 불가 속박), `freezeDuration`(빙결), `stunDuration`(기절) 속성을 내장하여 몬스터 FSM을 즉각 전환.
5. **극상의 타격감 (Combat Juice Pipeline)**:
   - 타격 순간 $0.08\text{s}$ 히트스탑(Hitstop), $0.12\text{s}$ 흰색 실루엣 마스크 플래시, 포물선 넉백($v_x = \text{dir} \times 3.2, v_y = -2.0$), 화면 진동(Screen Shake $2\sim 6\text{px}$).

### [Part 2] 전사 (Warrior) 계통도

```
[검사 (1차)]
    ├── [파이터 (2차)] ──── [크루세이더 (3차)] ──── [히어로 (4차)] (검/도끼)
    ├── [페이지 (2차)] ──── [나이트 (3차)] ─────── [팔라딘 (4차)] (검/둔기)
    └── [스피어맨 (2차)] ── [용기사 (3차)] ─────── [다크나이트 (4차)] (창/폴암)
```

#### 1. 검사 (1차 공통)
- **파워 스트라이크 (Power Strike)**:
  - *고증*: 무기를 단일 적에게 강하게 내리찍어 260%의 강력한 단타 피해.
  - *엔진 구현*: 전방 $100\text{px}$ 단일 타겟 AABB. 적중 시 0.08s 히트스탑 및 주황색 대형 절삭 이펙트 + 하향 넉백.
- **슬래시 블러스트 (Slash Blast)**:
  - *고증*: HP/MP를 동시 소모하여 전방 부채꼴 범위 내 최대 6마리의 적을 동시 타격하는 전사 핵심 광역기.
  - *엔진 구현*: 전방 원호 범위($\text{radius} = 110\text{px}, \theta = 140^\circ$) 다중 판정. 회전 검기 잔상 렌더링 및 타겟마다 $15\text{ms}$ 시차 대미지 분산.
- **아이언 바디 (Iron Body)**:
  - *고증*: 방어력을 비약적으로 상승시켜 피격 대미지를 감소시키는 버프.
  - *엔진 구현*: 상시 패시브(`isPassive: true`), 물리 방어력 +40 및 피격 시 방패 흡수 이펙트.

#### 2. 파이터 / 크루세이더 / 히어로 (검·도끼 계열)
- **분노 (Rage - 2차)**:
  - *고증*: 파티원의 물리 공격력을 대폭 증가시키고 방어력을 소폭 감소시키는 상징적 버프.
  - *엔진 구현*: 공격력 +20 상시 증폭. 캐릭터 머리 위 붉은 도깨비불 오라 펄스 렌더링.
- **콤보 어택 (Combo Attack - 3차)**:
  - *고증*: 적 타격 시마다 구슬(Combo Counter)이 누적(최대 5개)되어 타격당 대미지가 비례 증폭되는 전사의 핵심 코어.
  - *엔진 구현*: `user.comboCount` 상태 관리. 플레이어 주변을 회전하는 푸른빛 영혼 구슬 렌더링(반경 28px, 회전 속도 2.5rad/s). 구슬 1개당 최종 대미지 +10% 증폭.
- **패닉 (Panic - 3차)** & **코마 (Coma - 3차)**:
  - *고증*: 축적된 콤보 구슬을 일거에 소모하여 치명적인 암흑/기절 단타 및 광역 폭발을 일으킴.
  - *엔진 구현*: 패닉은 단일 적 $350\%$ + 암흑(명중률 -50%), 코마는 최대 6체 광역 $200\%$ + 5초 기절. 시전 시 화면 진동 4px.
- **브랜디쉬 (Brandish - 4차)**:
  - *고증*: 거대한 십자 검기를 허공에 2연속 작렬시켜 전방 1~2마리의 적을 쾌도난마로 베어내는 히어로의 상징.
  - *엔진 구현*: $150\text{px}$ 사거리, 2연타 시차($70\text{ms}$ 간격, 각 $260\%$). 십자 형태의 거대한 푸른 검기 슬래시 이펙트 및 타격 시 몬스터 양단 절삭 연출.
- **어드밴스드 콤보 (Advanced Combo - 4차)**:
  - *고증*: 콤보 구슬 최대치를 10개로 확장하고 타격 시 2개씩 누적될 확률 부여.
  - *엔진 구현*: 최대 구슬 10개, 최종 대미지 최대 1.9배 증폭, 자줏빛 황금 오라 렌더링.

#### 3. 페이지 / 나이트 / 팔라딘 (속성 차지 계열)
- **속성 차지 (Fire/Ice/Lightning/Holy Charge - 3~4차)**:
  - *고증*: 무기에 4대 원소(화염, 냉기, 전기, 성) 속성을 인챈트하여 몬스터 약점 타격 시 1.5배의 증폭 대미지 및 상태이상(빙결/감전) 부여.
  - *엔진 구현*: `user.weaponElement` 세팅. 타격 시 불꽃/얼음 파편/전기 스파크/성광 이펙트 방출. 빙결 취약 몬스터는 즉시 3초간 동결.
- **블래스트 (Blast - 4차)** & **생츄어리 (Sanctuary - 4차)**:
  - *고증*: 블래스트는 차지를 소모해 단일 적을 압도적 위력으로 분쇄, 생츄어리는 화면 전체에 거대한 신성 망치를 낙하시켜 최대 15체의 체력을 1로 만듦.
  - *엔진 구현*: 생츄어리 시전 시 전 화면 화이트아웃 플래시 + 거대 황금 묠니르 낙하 애니메이션 및 화면 진동 6px.

#### 4. 스피어맨 / 용기사 / 다크나이트 (창·폴암 계열)
- **하이퍼 바디 (Hyper Body - 2차)**:
  - *고증*: 최대 체력(MaxHP)과 마나(MaxMP)를 60% 폭증시켜 모든 파티원의 원킬 급사를 방지하는 최고의 유틸기.
  - *엔진 구현*: `user.maxHp *= 1.6`, `user.maxMp *= 1.6`. 황금빛 인간 형상 아우라 상승 연출.
- **드래곤 버스터 (Dragon Buster - 3차)**:
  - *고증*: 창 끝으로 전방 3마리의 적을 초고속 3연속 찌르기(3-hit).
  - *엔진 구현*: 사거리 140px, $40\text{ms}$ 간격의 3연속 찌르기 대미지 폰트 계단형 팝업.
- **드래곤 쓰레셔 (Dragon Thresher - 3차)** & **드래곤 로어 (Dragon Roar - 3차)**:
  - *고증*: 쓰레셔는 폴암을 크게 휘둘러 6체 관통 넉백, 로어는 자신의 체력 30%를 희생하여 화면 전체에 용의 포효 광역 타격.
  - *엔진 구현*: 로어 시전 시 전 화면 포효 음파 이펙트 및 전 필드 몬스터 동시 스턴(3초).
- **버서크 (Berserk - 4차)**:
  - *고증*: 체력이 40~50% 이하로 떨어지면 공격력이 2배 이상 폭증하는 하이리스크 하이리턴 패시브.
  - *엔진 구현*: `user.hp <= user.maxHp * 0.5` 감지 시 캐릭터 전신이 검붉은 화염으로 불타오르며 대미지 2.1배 강제 증폭.

### [Part 3] 마법사 (Magician) 계통도

```
[매지션 (1차)]
    ├── [위자드(불·독) (2차)] ── [메이지(불·독) (3차)] ── [아크메이지(불·독) (4차)]
    ├── [위자드(썬·콜) (2차)] ── [메이지(썬·콜) (3차)] ── [아크메이지(썬·콜) (4차)]
    └── [클레릭 (2차)] ───────── [프리스트 (3차)] ─────── [비숍 (4차)]
```

#### 1. 매지션 (1차 공통)
- **에너지 볼트 (Energy Bolt)**:
  - *고증*: 순수 마나 응축 구체를 단일 적에게 발사.
  - *엔진 구현*: 투사체 스피드 440, 푸른 마나 구체 회전 렌더링.
- **매직 클로 (Magic Claw)**:
  - *고증*: 마나의 손톱 2개를 소환하여 적을 2연속 긁어내림 (물리 방어력 무시).
  - *엔진 구현*: 대상 위치에 보랏빛 손톱 2조가 $60\text{ms}$ 간격으로 내리꽂히며 2연타 분할 대미지.
- **텔레포트 (Teleport - 정통 점텔 규격)**:
  - *고증*: 상하좌우 방향키 방향으로 $140\text{px}$을 순간이동. 공중 점프 중 시전 가능.
  - *엔진 구현*: 왜곡 구체 $\rightarrow$ 도착 지점 마나 폭발. 도착 지점 직하방 선분 발판 자동 흡착 착지(Snap).
- **매직 가드 (Magic Guard)**:
  - *고증*: 피격 피해의 80%를 HP 대신 MP로 대체 흡수하여 유리몸 법사의 생존을 책임짐.
  - *엔진 구현*: 상시 패시브(`isPassive: true`), 피격 시 MP 차감 처리 및 푸른 마나 보호막 점멸.

#### 2. 위자드 / 메이지 / 아크메이지 (불·독 계열)
- **파이어 애로우 (2차)** & **포이즌 브레스 (2차)**:
  - *고증*: 화염 화살 단타 타격 및 독 브레스를 통한 퍼센트 도트(DoT) 중독 부여.
  - *엔진 구현*: 중독된 몬스터는 초당 $5\%$ 체력 감소(녹색 기포 이펙트 지속).
- **포이즌 미스트 (Poison Mist - 3차)**:
  - *고증*: 필드에 거대한 독안개를 살포하여 몬스터의 체력을 1까지 고갈시키는 솔로 플레잉 최강기.
  - *엔진 구현*: 반경 $200\text{px}$ 독구름 파티클 영역 생성. 영역 내 진입한 모든 몹에게 초당 3중 도트 피해.
- **페럴라이즈 (Paralyze - 4차)** & **메테오 (Meteor - 4차)**:
  - *고증*: 페럴라이즈는 독화염 복합 속성 4연타 + 마비, 메테오는 하늘에서 거대 운석군이 낙하하는 전체 화면 즉발기.
  - *엔진 구현*: 메테오 시전 시 화면 암전 후 거대 불타는 메테오 6개가 지면을 강타하며 전 필드 $1,200\%$ 광역 타격.

#### 3. 위자드 / 메이지 / 아크메이지 (썬·콜 계열)
- **콜드 빔 (Cold Beam - 2차)**:
  - *고증*: 얼음 송곳을 머리 위에서 낙하시켜 단일 적 확정 동결.
  - *엔진 구현*: 수빙 기둥 낙하, 타격 몬스터 $3.5\text{s}$ 행동 정지(푸른 얼음 셰이더 적용).
- **썬더볼트 (Thunderbolt - 2차)**:
  - *고증*: 캐릭터 주변 전방위로 번개를 방전시켜 최대 6체를 동시 타격하는 국민 파밍기.
  - *엔진 구현*: 반경 $260\text{px}$, 번개 스파크 6가닥 방출, 방전 SFX 연동.
- **아이스 스트라이크 (Ice Strike - 3차)**:
  - *고증*: 거대한 빙산 폭발을 일으켜 6마리의 적을 동시 타격 및 동결.
  - *엔진 구현*: 지면에서 솟구치는 거대 빙산 3단 애니메이션.
- **체인 라이트닝 (Chain Lightning - 4차)** & **블리자드 (Blizzard - 4차)**:

    user.attackTimer = user.attackDuration * 1.15;
    window.audio?.playAttack?.();
    const aim = user.attackAim, facing = user.facing;
    const { damage, isCrit } = user.getDamage();
    const activeStar = user.activeStar || 'steely';

    // 본체 거대 수리검 (관통 6체)
    SkillRegistry.fireProjectile(user, game, {
      type: 'avenger_star',
      speed: 560,
      range: 580,
