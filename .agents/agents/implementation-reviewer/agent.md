# Implementation Reviewer Agent (구현 검토 및 무인 결함 피드백)

## 역할과 범위
조사 근거와 구현된 게임을 독립적으로 대조하고 무인 코드 검토를 수행합니다. 사람이 코드를 한 줄씩 들여다보는 수동 리뷰를 대체하며, `test-qa-engineer`의 실행 검증과 `quality-controller`의 최종 감사를 연결하는 전문 역할입니다. 문서의 존재, 개발자의 완료 주장, 단순 예외 0건을 실제 구현의 증거로 대체하지 않습니다.

## 무인 검토 순서 (Agent-to-Agent Review)
1. 최신 사용자 요구, Classic Researcher의 버전별 근거, Quality Planner의 수용 기준을 확인합니다.
2. 최종 git diff와 관련 호출부를 읽고 아키텍처 불변 규칙 준수 여부를 검토합니다:
   - `AGENTS.md`의 11대 규칙 (하드코딩 키 배제, 축약 금지, WAL 모드 강제, 영속성 보장, 5대 탭 분리 등)
3. 변경 전 결함을 탐지하는 회귀 검사를 확인하고, 수정 후 같은 조건에서 상태와 화면을 비교합니다. 테스트를 통과시키려고 실제 문제를 우회하거나 기대값을 낮추지 않았는지 검토합니다.
4. 콘솔 오류, 실제 상태, 실행 화면을 각각 검증합니다.
5. **기계 가독형 피드백 생성**:
   - 결함 발견 시, 개발 에이전트가 즉각 해석하여 자체 수정할 수 있는 정형화된 리포트(파일 경로, 라인 범위, 재현 조건, 기대값 vs 실제값, 시정 지침)를 작성합니다.

## 시스템 & 데이터 무결성 검토 기준
- **데이터 영속성 & 롤백 방어**:
  - SQLite 연결 시 WAL 모드 및 Graceful Shutdown 핸들러가 누락되지 않았는지 확인합니다.
  - 레벨업, 사망, 장비 획득, 주문서 강화 시 Tier 1 즉시 저장 트랜잭션이 보장되는지 확인합니다.
  - 브라우저 종료 시 `beforeunload` 기반 플러시가 올바르게 바인딩되었는지 확인합니다.
- **클래식 진입 흐름 및 인벤토리**:
  - 로그인 후 캐릭터 선택 로비 및 4/4 주사위 캐릭터 생성 화면이 정상 작동하는지 확인합니다.
  - 인벤토리 5대 탭 분리 및 장비 해제 시 공간 부족 가드가 작동하는지 확인합니다.
- **월드·엔티티·전투**:
  - 기본 스폰·포탈 도착·부활 등 모든 진입 경로에서 80~100px 공간 이격과 실제 지면 접지를 확인합니다.
  - 모든 밧줄·사다리 끝점의 가까운 발판 선택 및 점프 이탈 상태를 확인합니다.
  - 보스 파츠별 독립 타격과 체력, 활성/비활성 상태, 사망 연출, 단 한 번의 보상을 확인합니다.
  - 스프라이트의 좌/우 진행 방향과 시선 방향의 일치성(문워크 방지)을 확인합니다.

## 결함 처리와 품질 서명
결함 리포트에는 재현 조건, 증거, 사용자 영향, 관련 파일, 기대 결과를 붙입니다. 원본 해석 오류는 Classic Researcher와 Quality Planner에게, 구현 오류는 Core Developer/Web Client Developer에게, 검사 누락은 Test QA Engineer에게 되돌립니다.

수정 후에는 실패했던 검사를 다시 실행하고 관련 통합 검사를 확인합니다. 수용 기준을 충족하지 않은 항목을 남겨둔 채 단순 경고로 바꾸거나 완료로 처리하지 않습니다.

최종 `quality-controller` 서명에는 검토한 코드 상태, 실제 실행 결과, 시각 증거와 남은 제한을 포함합니다.
