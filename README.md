## 🌟 프로젝트 소개 (Overview)

OpenMaple Classic은 넥슨(Nexon)의 전성기 클래식 메이플스토리(2003~2010년 빅뱅 이전) 특유의 **선분 발판 물리(Foothold Line Math), 2등신 페이퍼돌 그래픽, 자릿수 시차 대미지 스킨 바운스, 자쿰 보스 레이드, 지능형 A\* 자동사냥**을 순수 HTML5/CSS3/JavaScript로 구현한 웹 게임 클라이언트입니다.

외부 번들러(Webpack, Vite)나 프레임워크(React, Vue) 없이, 웹 브라우저만 있으면 로컬에서 즉시 60FPS로 구동됩니다.

## 🕹️ 핵심 기능 및 시스템 (Key Features)

### 1. 🗺️ 공식 WZ 추출 5대 월드 맵 (Multi-Map World)
원작 WZ 데이터의 발판 선분 좌표와 사다리를 정밀 추출하여 5개 테마 맵을 완벽 구현했습니다:
- **헤네시스 사냥터 1 (`henesys_hhg`)**: 153개 발판, 8개 사다리/밧줄, 달팽이/슬라임/주황버섯 서식, 단풍나무와 버섯 언덕.
- **헤네시스 마을 (`henesys_town`)**: 220개 발판, 장로스탄, 마야, 중형택시 NPC, 버섯 초가집 테마.
- **던전: 개미굴 1 (`ant_tunnel`)**: 909개 발판, 20개 사다리, 좀비버섯/뿔버섯, 뼈사다리와 종유석 동굴.
- **요정의 마을: 엘리니아 (`ellinia`)**: 1,217개 발판, 37개 사다리, 거대 에메랄드 세계수 수직 지형.
- **보스 필드: 자쿰의 제단 (`zakum_altar`)**: 166개 발판, 용암 배경, 아도비스 NPC, 8개 팔을 지닌 거대 보스 자쿰 전용 필드.

### 2. 👑 8개 부속 팔 자쿰 보스 레이드 (Zakum Boss Raid)
- **100,000 HP 거대 본체 + 8개의 독립 부속 팔 (각 15,000 HP)**
- 각 팔은 독립된 피격 판정, HP 게이지, 부유 사인파 애니메이션, 대미지 폰트 연동, 파괴 이펙트를 가집니다.
- 주기적인 불기둥(`fire_pillar`), 벼락 낙뢰(`lightning`) 광역 기믹.
- 처치 시 **'자쿰의 투구(Zakum Helmet)'**, 10만 메소 다발, 엘릭서 등 고유 전리품 투하.
- 화면 상단 전용 와이드 보스 체력바 제공.

### 3. ⚔️ 5대 모험가 직업군 및 전투 스킬
- **초보자 (Beginner)**: 달팽이 세껍질, 기본 타격.
- **전사 (Warrior)**: 파워 스트라이크(단일 폭딜), 슬래시 블러스트(다수 관통기).
- **마법사 (Magician)**: 에너지 볼트, 매직 클로(2연타 마법).
- **궁수 (Bowman)**: 더블 샷(2연사 원거리 화살 투사체).
- **도적 (Thief)**: 럭키 세븐(2연속 럭키 표창 투사체), 플래시 점프(고속 공중 도약).

### 4. 🤖 지능형 위상 그래프 자동사냥 (Auto-Hunt AI)
- **위상 발판 그래프 (Foothold Graph)**: 맵 로드 시 발판(노드)과 사다리/하향낙하지점(에지)을 전수 분석하여 그래프를 자동 생성.
- **A\* 최단 경로 탐색**: 몬스터가 다른 층에 위치할 때 최적의 사다리 등반 및 하향 점프 경로를 산출하여 이동.
- **자동 루팅 (Auto-Loot) & 자동 물약 (Auto-Potion)**: 필드에 드롭된 메소와 아이템 우선 수거, HP/MP 임계치 이하 시 자동 섭취.
- **끼임 방지 (Anti-Stuck Watchdog)**: 0.5초간 변위가 10px 미만일 시 명령을 강제 취소하고 무작위 회피 도약 수행.
- **실시간 통계**: 사냥 시간, 처치 수, 분당 경험치(EXP/min), 분당 메소(Meso/min) 계측.

### 5. 🚕 NPC 대화 & 모범택시 시스템
- NPC(모범택시, 중형택시, 장로스탄, 베티, 마야, 아도비스) 근처에서 `Space` 키 입력 시 전용 양피지 다이얼로그 팝업.
- 목적지 선택 시 대륙 간 즉시 텔레포트 이동 지원.

### 6. 💬 인게임 채팅 & 말풍선 & 루팅 로그
- **하단 채팅창**: `[ALL]`, `[파티]`, `[길드]` 탭 지원 및 엔터키 입력.
- **머리 위 말풍선**: 입력한 대화가 캐릭터 머리 위에 4초간 클래식 말풍선(`Speech Bubble`)으로 렌더링.
- **우측 하단 루팅 로그**: 경험치, 메소, 아이템 획득 시 3.2초간 페이드아웃되는 플로팅 알림 로그.

### 7. 🔊 Web Audio API 프로시저럴 사운드 엔진
- 외부 MP3/WAV 파일 의존성 없이, 브라우저 오실레이터로 레트로풍 메이플 BGM 및 타격/점프/아이템/포션 효과음을 100% 프로시저럴 합성.

## 🎮 키 조작법 (Controls)

| 분류 | 키 (Key) | 기능 (Function) |
| :--- | :--- | :--- |
| **이동** | `←`, `→` | 좌우 이동 (공중 관성 및 마찰 적용) |
| **점프** | `Alt` | 점프 ($v_{jump} = -9.8$) |
| **하향 점프** | `↓` + `Alt` | 발판 아래로 관통 낙하 (`dropThroughUntilY`) |
| **사다리/밧줄** | `↑`, `↓` | 사다리 중심선($\pm 12\text{px}$) 흡착 및 등반 |
| **밧줄에서 점프** | `←` 또는 `→` + `Alt` | 방향을 주며 박차고 이탈. 점프만 누르면 매달림 유지 |
| **기본 공격** | `Ctrl` | 직업·무기에 맞는 기본 스킬 |
| **스킬 1~4** | `Shift`, `Q`, `W`, `E` | 현재 직업의 퀵슬롯 1~4 시전 |
| **스킬 5~8** | `A`, `S`, `D`, `F` | 현재 직업의 퀵슬롯 5~8 시전 |
| **아이템 줍기**| `Z` | 바닥의 메소 동전/주머니 및 아이템 수거 |
| **상호작용** | `Space` | NPC 대화창 열기 / 포탈 타기 |
| **포션 섭취** | `1`, `2` | 빨간 포션(HP 50), 파란 포션(MP 50) 복용 |
| **자동사냥** | `R` | **⚡ 지능형 자동사냥 ON / OFF** |
| **보스 소환** | `B` | **👑 머쉬맘 소환 (헤네시스 필드)** |
| **UI 창 토글**| `C` (스탯), `I` (인벤토리), `K` (스킬), `O` (자동사냥 설정) | 클래식 드래그 창 열기/닫기 |

위 표는 클래식 기본 키 설정입니다. 키 설정창에서 WASD 프리셋이나 사용자 지정 키를 적용할 수 있습니다. 설정된 게임 행동이 UI 단축키보다 우선하며, 사용 중인 키를 다른 행동에 지정하면 기존 행동의 키는 해제됩니다. 채팅 및 텍스트 입력 중에는 게임 단축키가 실행되지 않습니다.

## 🚀 실행 방법 (Getting Started)

Python 서버와 브라우저 QA에는 Python 3.11 이상 및 `websockets` 패키지가 필요합니다. 클라이언트 자체는 별도의 npm 패키지나 빌드 도구를 사용하지 않습니다. 최초 실행 전에 프로젝트 폴더에서 의존성을 설치하세요:

```powershell
python -m pip install -r requirements.txt
```

### 방법 1. 원클릭 실행 (Windows)
프로젝트 루트의 `run.bat` 파일을 더블 클릭하면 브라우저가 즉시 실행됩니다.

### 방법 2. Python 로컬 서버 실행 (권장)
```powershell
python server.py
```
실행 즉시 기본 브라우저(`http://localhost:8000`)가 열립니다.

### 방법 3. 브라우저로 직접 열기
`index.html` 파일을 크롬(Chrome), 엣지(Edge), 파이어폭스, 웨일 브라우저로 드래그 앤 드롭하여 바로 실행할 수 있습니다.

## 🧪 자동화 QA 검증 (Automated Testing)

본 프로젝트는 Headless Chrome DevTools Protocol(CDP) 기반 자동화 QA 러너를 탑재하고 있습니다.  
전체 맵 순회, 보스 레이드, 스킬 연계, UI 조작 중 발생하는 브라우저 콘솔 에러를 실시간으로 감지합니다.

```powershell
python run_qa.py
```

QA 실행 전에 `python server.py --no-browser`로 서버를 띄워 두세요. 기존 브라우저 QA 러너는 Windows의 `C:\Program Files\Google\Chrome\Application\chrome.exe`와 HTTP 포트 8000을 사용합니다.

전체 회귀 검증은 다음 순서로 실행합니다. 물리·전투·스킬·버프 단위 테스트는 Node.js의 내장 테스트 러너를 사용합니다.

```powershell
python test_multi_tier_pipeline.py
python run_qa.py
python game_qa_suite.py
python test_input_regressions.py
python test_sprite_grounding.py
python test_ladder_browser.py
node --test test_physics_regressions.js test_combat_collisions.js test_skill_states.js test_buff_stats.js
```

입력 회귀 테스트는 실제 브라우저 이벤트로 채팅 포커스 차단, 단일 물약 사용, WASD 및 사용자 지정 키, 동시 입력 우선순위, 사다리 방향 점프와 터치 취소를 검증합니다. 4가지 뷰포트(1280×800, 1024×768, 800×600, 390×844)에서 하단 HUD의 세로 잘림과 가로 스크롤 접근성도 확인합니다. 버프 테스트는 아이언 바디의 방어력 +25, 중복 적용 방지, 만료 복구 및 장비 보정을 검증합니다.

접지 회귀 테스트는 캐릭터·몬스터 PNG 172개를 양방향으로 실제 렌더링해 본체의 발끝이 물리 좌표에 닿는지 검사합니다. 살아 있는 프레임은 가장 큰 연결 영역을 본체로 판별하여 아래쪽의 분리된 이펙트 점을 발끝으로 오인하지 않습니다. 사망 프레임은 파편 연출을 보존하며 전체 실루엣을 정렬합니다. 기준점을 `js/sprite_grounding.js`에 미리 저장하므로 게임 루프에서 픽셀을 분석하지 않습니다. 캐릭터나 몬스터 PNG를 추가·교체했다면 Pillow가 설치된 개발 환경에서 `python generate_sprite_grounding.py`로 이 메타데이터를 갱신하세요. 지형 그림의 원점 보정은 맵 데이터의 `terrainOffset`으로 관리합니다.

### 물리 및 판정 감사 범위

5개 맵의 사다리·밧줄 75개와 끝점 150곳을 검사합니다. 브라우저 테스트는 CDP 키 입력으로 등반, 위층 착지, 하강, 무방향 점프와 좌우 점프 이탈, 이탈 후 관성을 확인합니다.

| 영역 | 적용한 규칙 및 수정 |
| :--- | :--- |
| 시간 스텝 | 게임 업데이트와 물리를 고정 60Hz로 실행하여 렌더 주기에 따른 차이 제거 |
| 등반 상태 | 밧줄을 잡는 순간 이전 발판을 해제하고, 등반 중 중력·지면 흡착을 차단 |
| 등반 끝점 | 가장 아래층이 아닌 해당 끝점의 가까운 발판에 착지. 지지면 없는 하단에서는 자연 낙하 |
| 밧줄 점프 | 좌우 입력과 점프를 함께 눌러 이탈. 점프 단독은 매달림을 유지하고, 재흡착 유예 적용 |
| 이동·넉백 | 지상 가속·마찰, 공중 제어와 관성을 분리하여 입력 해제가 점프·피격 속도를 지우지 않음 |
| 선분 충돌 | 이동 궤적과 경사 선분의 첫 교차에서 착지. 아래쪽에서 위로 끌어올리는 허용 오차 제거 |
| 하향 점프 | 현재 발판 층만 무시하여 가까운 아래층까지 관통하는 문제 제거 |
| 발판 분류 | 폭이 짧은 WZ 경사 조각도 정상 지형으로 취급하고 명시된 장식만 제외 |
| 공격·이동 스킬 | 사망·등반 중 시전 및 공격 쿨타임 우회 차단. 허약 점프 제한과 만료 적용. 텔레포트 후 접지 상태 재검사 |
| 투사체 | 실제 이동 선분의 첫 접촉을 선택하여 사선 사각형 오탐 및 타깃 배열 순서 의존 제거 |
| 맵·자동사냥 | 누락된 HHG 최상단 섬 발판 복구, 맵 경계의 지형 잘림 방지, 실제 등반 완료 후에만 명령 종료 |

일부 원본 지형 PNG가 WZ 발판 범위보다 좁습니다(마을 22px, 개미굴 600px, 자쿰 19px). 물리 범위는 발판과 밧줄을 포함하며 이미지 밖 발판은 선분에 맞춘 테마별 지형을 한 번 구워 보충합니다. 원본 PNG 내부는 유지합니다.
