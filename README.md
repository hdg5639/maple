# 🍁 클래식 메이플스토리 웹 (OpenMaple Classic) with 자동사냥 시스템

HTML5 Canvas와 Web Audio API로 구현된 추억의 **클래식 메이플스토리 (헤네시스 사냥터 1)** 웹 게임입니다.  
별도의 외부 설치나 복잡한 프레임워크 없이 로컬 웹 브라우저 환경에서 즉시 구동되며, 고성능 **자동사냥(Auto-Hunt AI) 엔진**이 탑재되어 있습니다.

---

## 🌟 주요 특징

1. **로컬 웹 즉시 실행 (Zero-Dependency)**
   - 순수 HTML5 / CSS3 / Vanilla JavaScript로 개발되어 별도의 빌드 과정이나 CDN 의존성 없이 로컬에서 바로 실행됩니다.
   - 더블 클릭으로 `index.html`을 바로 열거나, 동봉된 `run.bat` / `python server.py`로 로컬 HTTP 서버 구동 가능.

2. **🤖 지능형 자동사냥 (Auto-Hunt AI) 시스템**
   - **단축키 `[R]`** 또는 상단 버튼 클릭으로 원클릭 자동사냥 ON/OFF
   - **스마트 길찾기 & 층간 이동**: 발판 감지, 하향 점프(아래+점프), 사다리/밧줄 오르내리기, 점프 극복 AI
   - **자동 타겟팅 & 공격**: 가장 효율적인 몬스터를 탐색하고 스킬 연계(파워 스트라이크, 슬래시 블러스트, 매직 클로 등) 자동 시전
   - **자동 아이템/메소 루팅 (Auto-Loot)**: 드롭된 메소와 아이템을 우선 감지하고 수거
   - **자동 생존 & 물약 섭취 (Auto-Potion)**: HP/MP 임계치(기본 55% / 40%) 이하 도달 시 인벤토리의 빨간 포션 / 파란 포션 자동 복용
   - **실시간 통계 대시보드**: 누적 사냥 시간, 처치 수, 분당 경험치(EXP/min), 분당 메소(Meso/min) 실시간 추적

3. **추억의 그래픽 & 맵 재현**
   - **헤네시스 사냥터 1** 다층 발판, 버섯집, 풍차, 벚꽃/단풍나무, 사다리, 밧줄, 차원 포탈 구현
   - 클래식 몬스터 군단:
     - 🐌 달팽이 (초록 / 파랑 / 빨강)
     - 🟢 슬라임 (물컹물컹 바운스 모션)
     - 🍄 주황버섯 / 초록버섯
     - 🐷 리본돼지
     - 👑 **[BOSS] 거대 보스 머쉬맘 (단축키 `[B]`)**: 보스 전용 HP바 및 드롭 아이템
   - 클래식 캐릭터 애니메이션 (대기, 보행, 점프, 공격 베기 모션, 사다리 등반, 타격 피격, 묘비 & 유령 사망 모션)
   - 클래식 타격감: 무지개/크리티컬 데미지 폰트 바운스, 타격음, 미스(MISS) 이펙트

4. **Web Audio API 프로시저럴 사운드 엔진**
   - 헤네시스 풍의 따뜻하고 경쾌한 BGM 신디사이저 재생 (`[🎵 BGM 토글]`)
   - 점프음, 칼 휘두르는 소리, 타격음, 몬스터 피격/처치음, 코인 짤랑이는 소리, 포션 꿀꺽음, 레벨업 팡파레 완벽 합성

5. **정통 RPG 시스템 & UI**
   - 드래그 가능한 클래식 메이플 윈도우 창
   - **스탯창 `[S]`**: STR, DEX, INT, LUK 분배 및 실시간 공격력 계산
   - **인벤토리 `[I]`**: 소비/장비/기타 탭, 포션 클릭 사용, 메소 보유량
   - **스킬창 `[K]`**: 파워 스트라이크, 슬래시 블러스트, 매직 클로, 플래시 점프, 회복력 향상
   - **1차 전직 시스템**: Lv.10 달성 시 전사, 마법사, 궁수, 도적 전직 팝업 제공
   - 자동 저장 (`localStorage`) 지원

## 🚀 로컬 실행 방법

### 방법 1. 윈도우 배치 파일 (가장 간편)
`run.bat` 파일을 더블 클릭하여 실행하면 브라우저가 자동으로 열립니다.

### 방법 2. Python 로컬 서버 실행
```bash
python server.py
```
실행 시 자동으로 브라우저(`http://localhost:8000`)가 열립니다.

### 방법 3. 브라우저로 직접 열기
`index.html` 파일을 크롬(Chrome), 엣지(Edge), 웨일, 파이어폭스 등 웹 브라우저로 드래그 앤 드롭하거나 더블 클릭하여 바로 플레이할 수 있습니다.

## 🎮 조작법 (Key Controls)

| 키 (Key) | 기능 (Function) |
| :--- | :--- |
| **방향키 `←`, `→`** | 좌우 이동 |
| **방향키 `↑`, `↓`** | 사다리 / 밧줄 오르내리기 |
| **`Alt` 또는 `C`** | 점프 |
| **`↓` + `Alt`** | 발판 아래로 떨어지기 (하향 점프) |
| **`Ctrl`** | 기본 공격 |
| **`Shift` / `Q`** | 파워 스트라이크 (Power Strike) |
| **`W`** | 슬래시 블러스트 (Slash Blast) |
| **`E`** | 매직 클로 (Magic Claw) |
| **`F`** | 플래시 점프 (Flash Jump) |
| **`Z`** | 아이템 / 메소 줍기 |
| **`1`** | 빨간 포션 사용 (HP 50 회복) |
| **`2`** | 파란 포션 사용 (MP 50 회복) |
| **`R`** | **⚡ 자동사냥 ON / OFF (Auto-Hunt)** |
| **`B`** | **👑 보스 머쉬맘 소환 (Summon Boss)** |
| **`S`** | 능력치 스탯창 열기/닫기 |
| **`I`** | 아이템 인벤토리 열기/닫기 |
| **`K`** | 스킬창 열기/닫기 |
| **`O`** | 자동사냥 세부설정 열기/닫기 |

## 📁 프로젝트 파일 구조

```
openmaple/
├── index.html          # 메인 HTML5 인터페이스 및 HUD, 팝업
├── style.css           # 레트로 메이플 테마 CSS, 퀵슬롯, 드래그 창
├── server.py           # 초경량 로컬 파이썬 웹 서버
├── run.bat             # 윈도우 원클릭 실행 스크립트
├── js/
│   ├── audio.js        # Web Audio API 신디사이저 (BGM + 효과음)
│   ├── sprites.js      # 캐릭터, 몬스터, 이펙트 벡터 그래픽 렌더러
│   ├── map.js          # 헤네시스 사냥터 1 발판, 배경, 포탈 엔진
│   ├── physics.js      # 중력, 발판 충돌, 사다리 2D 물리 엔진
│   ├── entities.js     # 플레이어, 몬스터, 드롭 아이템, 데미지 엔티티
│   ├── autohunt.js     # 자동사냥 AI 엔진 및 실시간 통계 분석
│   ├── ui.js           # 드래그블 윈도우, 인벤토리, 스탯, 단축키 UI
│   └── game.js         # 메인 게임 루프, 카메라, 스폰, 세이브
└── README.md           # 상세 프로젝트 문서
```
