# 🛠️ OpenMaple 개발 및 에셋 파이프라인 도구 (Tools)

게임 에셋 추출, 동기화, 스프라이트 베이킹 및 정적 무결성 감사를 위한 자동화 도구 모음입니다.

---

## 📁 디렉토리 구조

- **`asset_pipeline/`**: WZ 에셋 동기화, 오프스크린 스프라이트 베이킹, 표창 및 이펙트 데이터 생성
- **`map_tools/`**: WZ 맵 데이터 추출, 선분 발판 변환, `js/map_data.js` 빌드
- **`scrapers/`**: WZ 리소스 및 몬스터/직업 스프라이트 다운로더
- **`audits/`**: 정적 에셋 누락 감사(`audit_assets.py`), UI 메서드 감사, 레퍼런스 캡처 도구
